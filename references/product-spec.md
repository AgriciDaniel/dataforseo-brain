# DataForSEO Brain Product Spec

## Buyer

SEO engineers, agencies, and AI/GEO builders who need a source-cited operating memory of the DataForSEO API: endpoints, parameters, request lifecycle, costs, and adapters.

## Domain

DataForSEO v3 API mastery — 12 modules and ~200+ endpoints (SERP, Keywords Data, AI Optimization, Domain Analytics, DataForSEO Labs, OnPage, Backlinks, Content Analysis, Merchant, App Data, Business Data, Databases), the task/live queue execution model, and the per-call cost model.

## Core Workflows

- API surface intake and provenance capture
- Endpoint selection and request design
- Cost estimation and budget governance
- Sandbox and live test with fixture capture
- Workflow synthesis and report rendering

## Deliverables

- API capability map and endpoint reference
- Request-lifecycle and cost-control playbooks
- Workflow pipelines (rank tracking, keyword research, backlink audit, site audit, local SEO, AI visibility, e-commerce)
- Decision guides (which API for which job, live vs standard, MCP vs REST, vs competitors)
- Adapter that normalizes DataForSEO responses into vault records

## Promise

Turn raw sources and recurring decisions into a persistent, source-cited
operating brain.

## Non-Promises

- No endpoint, parameter, cost, or auth claim without a current official docs citation
- No credentials, tokens, or .env values in any repo artifact; secrets stay in ~/Desktop/Keys
- No live billable API call beyond the operator-approved $5 cap; track spend via the user_data endpoint and hard-stop
- No irreversible recommendation without owner, confidence, source, and rollback note
